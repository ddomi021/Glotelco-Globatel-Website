# Globatel (Puerto Rico)

Marketing site for **Globatel** — the Puerto Rico brand for business phone systems. (US brand lives on a separate site.)

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Run locally

Node.js 20+ required.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
